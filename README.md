# 1. OnaiZhol Smart Cities & Mobility
**Название:** OnaiZhol

**Трек:** [Smart Cities & Mobility]

# 2. Проблема и целевая аудитория
**Проблема:** В часы пик светофоры с фиксированным таймером создают искусственные заторы и давку на остановках, так как не учитывают реальный поток машин и количество ожидающих пассажиров.

**Целевая аудитория:** Водители, теряющие время в пробках; пассажиры общественного транспорта, мерзнущие на остановках; акиматы и автопарки, теряющие деньги на неэффективной логистике.

# 3. Описание решения и ключевая AI/ML-логика
**Решение:** Прототип адаптивной системы управления перекрестком.

**AI-логика:** Используется модель компьютерного зрения (YOLOv8) для анализа видеопотока с уличных камер в реальном времени. Модель детектирует и подсчитывает количество автомобилей. На основе этих данных скрипт (кастомная логика) динамически принимает решение о продлении или сокращении зеленого сигнала светофора. 

# 4. Технологический стек
* **Язык:** Python

* **Computer Vision:** YOLOv8 (ultralytics), OpenCV

* **Обработка данных:** NumPy

# 5. Инструкция по локальному запуску
1. Скачайте файлы проекта на свой компьютер (или склонируйте репозиторий).

2. Убедитесь, что у вас установлен Python, и установите нужные библиотеки через терминал:
   pip install ultralytics opencv-python

3. Откройте терминал (cmd) в папке с проектом и запустите скрипт:
   python main.py

*(Примечание: при самом первом запуске скрипт автоматически скачает файл весов нейросети yolov8n.pt)*
